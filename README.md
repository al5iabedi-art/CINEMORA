# CINEMORA 2.0 PRO

آرشیو سینمایی کلاسیک با جستجوی داستانی، پنل ادمین امن، و توکن TMDB که فقط سمت سرور نگهداری می‌شود.

## معماری
- `server.js` — بک‌اند Node/Express: تمام درخواست‌های TMDB از اینجا رد می‌شوند، توکن هرگز به مرورگر ارسال نمی‌شود.
- `public/index.html` — سایت اصلی (فرانت‌اند)، فقط با بک‌اند خودتان صحبت می‌کند.
- `public/admin.html` — پنل مدیریت خصوصی، با رمز عبور محافظت می‌شود.
- `data/db.json` — ذخیره لینک‌های «کجا ببینمش؟» و آمار سایت (فایل ساده JSON).

## اجرا روی سیستم خودتان
```bash
npm install
cp .env.example .env
# .env را باز کن و TMDB_TOKEN و ADMIN_PASSWORD را پر کن
npm start
```
سپس سایت روی `http://localhost:3000` و پنل مدیریت روی `http://localhost:3000/admin.html` در دسترس است.

### گرفتن TMDB Token
حساب TMDB بساز → Settings → API → بخش «API Read Access Token» را کپی کن و در `.env` به‌عنوان `TMDB_TOKEN` قرار بده.

### رمز پنل ادمین
یک رمز قوی در `ADMIN_PASSWORD` بگذار. این رمز فقط روی سرور است و در کد فرانت‌اند وجود ندارد.

## میزبانی آنلاین (رایگان/ارزان)
چون این پروژه یک بک‌اند دارد، باید روی سرویسی اجرا شود که Node.js را پشتیبانی کند (نه هاست استاتیک ساده):
- **Render.com** یا **Railway.app**: مخزن را وصل کن، Build command خالی، Start command: `npm start`، متغیرهای محیطی (`TMDB_TOKEN`, `ADMIN_PASSWORD`) را در بخش Environment وارد کن.
- **Fly.io** یا یک VPS ساده هم کار می‌کند.
- Vercel/Netlify برای این ساختار مناسب نیستند مگر اینکه سرور را به Serverless Functions تبدیل کنی (تغییر ساختار لازم دارد).

⚠️ توجه: `data/db.json` روی هاست‌های سرورلس/کانتینر موقت ممکن است در هر ری‌استارت پاک شود. برای پایداری در محیط پروداکشن، بهتر است بعداً این فایل را به یک دیتابیس واقعی (مثلاً SQLite با دیسک دائمی، یا Postgres) مهاجرت بدهی. برای شروع و استفاده شخصی/کم‌ترافیک همین فایل کافی است.

## قبل از انتشار عمومی
1. در `public/index.html` بخش فوتر، `[نام شما]` و `[یوزرنیم شما]` را با نام و اینستاگرام خودت جایگزین کن.
2. مطمئن شو `.env` هرگز به گیت‌هاب پابلیک پوش نمی‌شود (در `.gitignore` هست).
3. رمز ادمین را طوری انتخاب کن که حدس‌زدنی نباشد؛ صفحه `/admin.html` نمایه (index) نمی‌شود ولی آدرس آن مخفی نیست، پس رمز قوی مهم است.

## چه چیزهایی از چک‌لیست پیاده شده
- جستجوی داستانی فارسی/انگلیسی بدون نیاز به اسم اثر (چندلایه: عنوان + کلیدواژه موضوعی + ژانر)
- بخش CINEMORA Clues زیر هر نتیجه و در صفحه جزئیات
- فیلتر فیلم/سریال/انیمه/انیمیشن
- صفحه‌بندی «نمایش بیشتر»
- پوستر/بک‌گراند واقعی و امتیاز TMDB
- کشور، سال، ژانر، مدت، کارگردان، بازیگران، تریلر، آثار مشابه
- بخش Discovery (پیشنهاد تصادفی از پرطرفدارهای هفته)
- علاقه‌مندی‌ها و تاریخچه جستجو (در مرورگر کاربر)
- «کجا ببینمش؟» با ترکیب اطلاعات TMDB و لینک‌های دستی شما
- پنل ادمین با رمز، مدیریت لینک‌ها، و آمار بازدید/جستجو
- کش ۱۰ دقیقه‌ای روی درخواست‌های TMDB برای سرعت بهتر
- حالت خطا / بدون‌نتیجه / قطعی API در فرانت‌اند
- بدون هیچ اشاره‌ای به هوش مصنوعی در ظاهر سایت

## محدودیت صادقانه
جستجوی داستانی از تطبیق کلیدواژه + ژانر + عنوان استفاده می‌کند (نه یک مدل زبانی)، پس دقتش به کیفیت توضیح شما و پوشش دیتابیس TMDB بستگی دارد؛ برای توضیحات مبهم ممکن است نتایج حدسی‌تر باشند.
